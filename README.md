# 小鹅通智能批改工作台

面向网络安全、运维等技术课程的小鹅通智能批改工作台。老师输入小鹅通作业地址与批改要求，系统启动独立 Chrome 完成登录、读取学生提交并填写“老师点评”；浏览器扩展为可选能力。

## 当前版本

- 支持小鹅通 `commit_detail` 作业提交详情页。
- 默认使用独立 Chrome 执行，支持扫码登录与店铺选择后的自动回跳，不依赖当前打开工作台的浏览器。
- 浏览器扩展为可选功能，可用于后续浏览器内执行，不会阻塞默认批改流程。
- 读取学生公开博客、代码和小鹅通图片作业；图片会下载后转为 Base64 再交给视觉模型。
- 支持任意 OpenAI 兼容接口：中转站、GPT、DeepSeek、Qwen 等。
- 自动批改、自动提交、实时进度、暂停、失败记录和本地导出。
- API Key 仅保留在当前本地进程内，不写入磁盘、不上传至本项目服务端。

## 使用

```powershell
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:4317`，填入小鹅通学生作业链接和批改要求后点击“启动自动批改”。系统会打开独立 Chrome；扫码后若进入店铺列表，选择对应店铺即可，系统会自动回到原作业链接。

### 一键临时网页

双击 `启动临时网页.bat`。脚本会启动本地工作台、建立 Cloudflare Quick Tunnel、自动打开新网页地址，并将地址写入 `dist/latest-url.txt`。Quick Tunnel 失效后再次双击即可重新生成地址。

### 面向老师的首次安装

老师下载仓库压缩包并解压后，双击 `安装并启动.bat`。安装程序只会询问一次机构 API Key，其余步骤会自动完成：下载便携 Node、安装依赖、准备扩展包，并在桌面创建 `Xiaoe Grader` 启动入口。之后只需双击桌面入口即可使用；浏览器扩展安装为可选项。

## 在线部署

本仓库附带 `render.yaml`。在 Render 新建 Blueprint，选择本仓库后，设置 `XIAOE_GRADER_MODEL_API_KEY`，即可得到固定的 `https://<服务名>.onrender.com` 工作台地址。扩展已允许 `*.onrender.com` 工作台域名。

### 机构部署

面向机构老师时，前端默认使用机构模型服务地址，老师不需要填写 Key。部署工作台的服务主机必须在启动前设置 `XIAOE_GRADER_MODEL_API_KEY`；参考 `.env.example`。浏览器扩展不包含 API Key。

本地缓存以“批改要求 + 模型 + 网页正文/代码/图片地址”的 SHA-256 内容指纹为键，保存 30 天。相同内容的重试或重复提交会复用历史评价，避免再次调用模型；内容、规则或模型发生变化则重新评估。

## 可靠性与恢复

- 页面加载、学生博客读取、模型调用会进行有限的指数退避重试。
- 点评提交只会点击一次；如果页面未切换，工具会回到提交列表核对 `未点评` 数量，绝不盲目重复提交。
- 每个学生的处理阶段和断点会立即写入本地任务记录。任务暂停后，页面提供“分析原因并继续”，从小鹅通当前未点评列表继续，不会从头重复批改。
- 运行时诊断基于页面状态、错误码、未点评数量和最后断点；它不会用模型编造失败原因。

## 必要边界

- 登录、验证码和账号选择必须由老师本人完成。
- 开启“自动提交点评”后，系统会在小鹅通中实际提交文字点评；任务页会明确显示这一状态。
- 仅处理老师有权限批改的作业，不尝试绕过站点的登录或安全验证。
- 小鹅通页面结构变动时，应更新 `src/xiaoe-adapter.mjs` 的页面适配逻辑；如启用扩展模式，还应同步更新 `extension/xiaoe-content.js`。
