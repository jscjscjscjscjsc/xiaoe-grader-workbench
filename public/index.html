执行动态

OPTIONAL BROWSER MODE

需要浏览器内执行时，再安装扩展

未安装扩展也可直接使用，系统会启动独立 Chrome 完成登录和批改。扩展仅用于在老师当前 Chrome 或 Edge 标签页内执行。

① 下载扩展压缩包
② 打开 Chrome 扩展页② 打开 Edge 扩展页
提示：下载后解压压缩包，会得到一个 xiaoe-grader-extension 文件夹，里面有使用说明。如果 manifest 文件没有显示 .json 后缀，这是 Windows 设置导致的，不影响安装。
  1. 点击上方"下载扩展压缩包"，解压到本机任意位置（解压后得到 xiaoe-grader-extension 文件夹）。
  2. 点击对应浏览器按钮打开扩展管理页，开启页面右上角的"开发者模式"开关。
  3. 点击"加载已解压的扩展程序"（Edge 为"加载解压缩的扩展"），选择解压出来的 xiaoe-grader-extension 文件夹。
  4. 安装成功后返回本页面刷新（F5），顶部显示"扩展已连接"后，任务会优先使用浏览器内执行。
